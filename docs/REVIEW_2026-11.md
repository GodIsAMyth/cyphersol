# CypherSOL Platform: Comprehensive Code & UI/UX Review

**Scope:** `/Users/manu/Library/CloudStorage/OneDrive-Personal/AML`. This covers ingestion (tabular, PDF and OCR), NLP categorisation and entity resolution, CypherEdge (Tally, ITR, Loan), CypherTrace (graph, bidirectional, layering, loops, mule scoring, profiles), the backend service and storage, the LLM agents, the test suite and the UI. It is measured against the SRS and the brochure.

**Method:** Each area got a static review, targeted experiments and benchmarks on the bundled samples and synthetic data, and then an independent verification pass on every critical or high finding. All 14 unit tests pass (about 30 s), but they do not exercise most of the defects below.

**Limitation:** No live browser pass was run. UI layout claims, including mobile width, come from reading the CSS. Console and network checks and screenshots are still outstanding.

**ID note:** Two UI review passes both used `UI-nn` numbering. Below, `UI-S-nn` is the structural code pass and `UI-L-nn` is the flow/"live" pass.

## 1. Executive Summary

**Overall verdict: not ready for evidentiary or production forensic use.** The architecture is sound: an offline-first cascade, Decimal money handling, the 52-category taxonomy matching the SRS exactly, correct Brandes betweenness and Tally double-entry signs, and consistent HTML escaping. But several core pipelines produce wrong numbers silently:

- Rows are dropped or merged in ingestion.
- Debit and credit are inverted in one bundled HDFC sample.
- Person-to-person transfers get confident lifestyle and crypto categories.
- FIFO layering attributes 180% of a credit.
- Loan ABB is mixed across accounts.
- The ITR report merges financial years under one label.

Several headline claims are not met in substance:

- 100% offline (NFR-SEC-01).
- Encrypted vault (NFR-SEC-02).
- A knowledge base of 7,500+ curated data points.
- 100+ bank templates.
- Deterministic Tally GUIDs.
- An "air-gapped" Sec 63 certificate.

Performance misses NFR-PERF-01 by 5x to 600x.

## 3. Critical & High Findings (verified, deduplicated)

Format: **ID(s)** · severity · `file:line`, then the impact and the fix. IDs merged from other areas are listed in brackets.

### 3.1 Security & privacy (cross-cutting)

1. **SEC-A: Unauthenticated local API that other sites can drive (CSRF / DNS rebinding), including a Tally push to any host** [BE-01, LLM-04, EDGE-01, LLM-05, UI-L-20] · **Critical** · `server.py:54-72, 231-239, 321-327`, `edge/tally_exporter.py:169-183`
   - **How it is reachable:** `_read_json_body` parses `text/plain` bodies as JSON, so a cross-site POST needs no preflight. There are no Origin or Host checks and no token. The wildcard ACAO header appears only on OPTIONS, so it is not the enabler.
   - **Impact:** A hostile page can rewrite the LLM provider, mode and API key, merge entities, or push a full case ledger to an attacker-chosen host. The fixed demo case IDs make this easy (`CASE_TRACE_EOW_041`), and DNS rebinding unlocks every read API.
   - **Fix:**
     - Require `Content-Type: application/json` on POST.
     - Validate Origin and Host against loopback on the bound port.
     - Use a per-launch token header.
     - Remove the wildcard CORS header.
     - Restrict the Tally host to loopback or a configured allow-list.
     - Audit rejected requests.
2. **SEC-B: No encryption at rest; API keys stored in plaintext; vault inside OneDrive** [BE-03, LLM-03] · **Critical** · `storage.py:1, 39, 595-607`; `llm_agents.py:243-244, 265-270`; `service.py:82`; `cli.py:133, 186-190`
   - **Impact:** Statements, PII, findings and provider keys are world-readable (`-rw-r--r--`) and synced to the cloud. Keys that were only exported in a shell get persisted after a mode-only update.
   - **Fix:** Use SQLCipher with a key from the OS keychain. Store secrets in `keyring` and never persist environment-sourced keys. Set file modes 0600/0700. Move the default vault to `platformdirs.user_data_dir`. Fix the docstring.
3. **LLM-01 / LLM-02: Cloud egress on by default; the "Heuristics only" setting is bypassed** · **High** · `llm_agents.py:198, 229-232, 265-287, 1196-1208`; `service.py:521`
   - **Impact:** If any `GEMINI_/ANTHROPIC_/OPENAI_API_KEY` is set, narrations, account numbers and page images go to the cloud. `run_case_llm_agents` uses `execution_mode or "both"`, which ignores the saved heuristics mode.
   - **Fix:** Default to `heuristics`. Do not import environment keys without `CYPHERSOL_ALLOW_CLOUD_LLM=1`. Change `service.py:521` to pass `execution_mode` through. Add an air-gap flag enforced in the transport. Add tests.
4. **LLM-06: Prompt injection through narrations can rewrite amounts, categories and merges** · **High** · `llm_agents.py:805-905, 1038-1093, 1127-1136`
   - **Impact:** A UPI remark controlled by a suspect can change debit, credit, balance or date on any row (not only rows that were sent), recategorise `USER_RULE` rows, or merge arbitrary entities.
   - **Fix:** Delimit narration as data only. Accept Stage 2 repairs only for rows that were sent and that restore balance continuity, and keep them as analyst-approved proposals. Accept 4A only for target `tx_id`s that are not USER_RULE rows. Accept 4B merges only when they are in `candidate_pairs`, and show them as suggestions.
5. **LLM-07: The LLM silently changes financial figures with no provenance** · **High** · `llm_agents.py:871-911` (the anomaly gate re-run then erases the `BALANCE_MISMATCH` evidence)
   - **Fix:** Keep `original_*` fields and an `LLM_REPAIRED` flag that the gate preserves. Write per-row before/after values to the audit log. Require analyst confirmation before export. Related: ING-10 (OCR self-healing, medium).
6. **BE-02: No authentication or RBAC, and binding to 0.0.0.0 is allowed** · **High** · `server.py:22`, `cli.py:131, 196`, `storage.py:199` (the actor is always `local_operator`)
   - **Fix:** Optional local login with scrypt and SameSite=Strict cookies, a single role check in `do_GET`/`do_POST`, and principal propagation into the audit and provenance records. Refuse a non-loopback host without authentication.
7. **BE-04: Chain of custody is incomplete and can be changed** · **High** · `storage.py:66-88, 297`; `service.py:610-611`; `reporting.py:399`; `ui/app.js:324`
   - **Impact:** No parser version, analyst or file size is recorded. `INSERT OR REPLACE` can overwrite provenance. The PDF prints a 16-character hash.
   - **Fix:** An append-only `statement_provenance` table with abort triggers. UPSERT that excludes the hash and timestamp columns. The full 64-hex digest in the PDF and UI.
8. **BE-05: The audit log can be edited and misses required actions** · **High** · `storage.py:175-182`; `service.py:81-134, 295-313, 696-699`; `server.py:194-201`
   - **Fix:** `BEFORE UPDATE/DELETE` abort triggers plus a `prev_hash`/`row_hash` chain. Log Draw Tool saves, LLM config changes (never key values), Tally XML downloads, and alias→canonical merge pairs.
9. **PDF-01: Catastrophic regex backtracking (ReDoS) in the TJ parser** · **High** · `pdf_parser.py:207-224`
   - **Impact:** Ambiguous alternation combined with BT/ET splitting on a standalone `(ET)` literal gives exponential time. This runs on every PDF before Poppler, so a crafted file locks a worker indefinitely.
   - **Fix:** Use an unambiguous alternation `[^\[\]()<>]`, a real content-stream tokenizer, and a per-page size or time cap.

### 3.2 Ingestion: tabular

10. **ING-01: Undated, invalid-date or US-dated rows are merged into the previous narration or dropped, so their amounts are lost** · **Critical** · `ingestion/parser.py:1289-1312`
    - **Impact:** In a US CSV, 3 rows became 1. A `31/02/2026` row with a 500 debit vanished. `meta['warnings']` stays empty and no flag is set. Fund trail, mule and loop results are computed on incomplete data.
    - **Fix:** Treat a row as a continuation only when all of its amount and balance cells are empty. Otherwise emit it with a `DATE_UNPARSEABLE` flag or a warning. Detect US date order once per file.
11. **ING-02: No DD/MM vs MM/DD resolution (FR-ING-06.3)** · **High** · `parser.py:30-49, 215-271`
    - **Impact:** `04/01/2026` becomes 4 Jan. `12/25/2025` is "repaired" to 2025-05-12 and `01-31-2026` to 2026-01-01.
    - **Fix:** A statement-level order pass (a field greater than 12 decides; otherwise monotonicity within the period), an `order` argument on `parse_indian_date`, OCR repairs only for OCR sources, and an ambiguity flag.
12. **ING-03: Fixed-width `.txt` files are split on the commas in Indian amounts** · **High** · `parser.py:463-472`
    - **Fix:** Mask `\d,\d` before counting delimiters. Require consistent field counts. Otherwise slice by header character offsets. Add a regression test.
13. **ING-04: Blank cells shift columns; positional mapping has no realignment** · **High** · `parser.py:472, 1338-1352`
    - **Impact:** A credit of 150000 was read as a debit with balance 0. Every row of the bundled HDFC PDF has both debit and credit set, opening −1000 and closing 0, with no warning.
    - **Fix:** Realign by token x-position (PDF) or header offsets (TXT). As a fallback, infer direction from the balance delta. Warn when both amounts are non-zero or when the mismatch rate is high. Related: PDF-03.
14. **ING-05: Only the first worksheet is parsed** · **High** · `parser.py:1184`
    - **Fix:** Iterate all sheets, skip sheets with no transaction header, concatenate in order with the sheet name recorded, and warn about skipped sheets.
15. **ING-06: `.xls` is unsupported and there is no charset detection** · **High** · `parser.py:452-461, 1180-1193`
    - **Fix:** Use xlrd or calamine (or return a clear "resave as .xlsx" error). Order decoding as BOM sniff, then charset-normalizer, then utf-8, then cp1252, with latin-1 last. Raise on NUL characters.
16. **ING-07: Unknown banks default to SBI and get a fabricated IFSC (`<prefix>0001234`)** · **High** · `parser.py:364, 380`; `anomaly_gate.py:107`
    - **Fix:** Use an `UNKNOWN` profile with `ifsc_code=None`, and raise statement-level `MISSING_METADATA` for IFSC, period and bank.
17. **ING-08: First-match substring bank detection** · **High** · `parser.py:352-355`
    - **Impact:** CBI becomes BOI, South Indian becomes INDIAN, and "Kasbi Traders" becomes SBI. The IFSC found at the same time is never cross-checked (it returned BOI with CBIN… in one result).
    - **Fix:** The IFSC prefix wins. Otherwise use the longest word-boundary keyword. Log conflicts.
18. **ING-14 / PDF-15: Bulk ingest uses threads, and one bad file aborts the whole batch** [BE-11 medium] · **High** · `parser.py:1442-1462`; `service.py:346`; `server.py:341-342`
    - **Impact:** 4 x 30k rows took 9.07 s on threads against 8.0 s serial. One encrypted or unsupported file throws away 99 good ones.
    - **Fix:** Catch errors per file and return a per-file status. Use `ProcessPoolExecutor(os.cpu_count())` for large batches. Persist the successful files and report the failures.

### 3.3 Ingestion: PDF and OCR

19. **PDF-03: "DD Mon YYYY" and ISO date-time statements are parsed with balances as credits** · **Critical** · `pdf_parser.py:464, 653-657, 703-718, 740, 749`
    - **Impact:** The header is found and then discarded, giving `(None, None, 0)`. The bundled CASE041 HDFC sample has 8/8 rows corrupted. `01 Apr 2025` reproduces it. This is a default format for HDFC, ICICI and Kotak.
    - **Fix:** One tolerant date-token predicate (including split `01 Apr 2025` tokens and a time suffix). Keep strong header splits even when body detection fails. Add regression tests on CASE041.
20. **PDF-04: Poppler is skipped for TJ-kerned (Ghostscript/report-engine) PDFs, giving 0 transactions** · **High** · `pdf_parser.py:253-267, 1376-1387`
    - **Fix:** Prefer Poppler whenever it is installed. Turn TJ displacement into new tokens at the advanced x.
21. **PDF-05: Native text is thrown away and re-OCR'd when narrations contain `NEFT:HDFC`-style tokens and the PDF has any image (a logo)** · **High** · `pdf_parser.py:1297-1308, 1401`
    - **Impact:** 0 s becomes 11.3 s, OCR self-healing then rewrites amounts, and the result is garbage on hosts without Vision or Tesseract.

## 5. UI/UX Review

### 5.1 What works

- **Safety:** All untrusted text passes through `esc()` at innerHTML sinks. The Tally preview uses `textContent`, and the HTML dossier uses `html.escape`.
- **Foundation:** A coherent token-based light palette, sticky table headers, `tabular-nums`, en-IN lakh/crore grouping, native `<dialog>` modals, and a tier badge palette that matches the 80/50 thresholds.
- **Forensic vocabulary:** The layering cards follow the SRS (Credit Source / Has Statement / Details Only, Amount Spent, Move to Misc). The mule weight labels match the backend. The SHA-256 custody column and the audit log view are visible.
- **Graph basics:** Pan and zoom with drag-vs-click disambiguation, a conduit-focus sub-view, a centrality table, and listeners bound once.
- **End-to-end wiring:** Tally preview, push and download; ITR flags; and the loan calculator with FOIR, rate and tenure inputs all work.

### 5.2 What is dated or broken

- **Layout and chrome:** No responsive breakpoints, no dark mode, and the Inter font is declared but never loaded. Three stacked header bars plus a KPI strip push content below the fold.
- **Feedback model:** `alert()` popups, silent failures, no loading or skeleton states, raw `JSON.stringify` output in KPI tiles, and raw XML dumps.
- **No data visualisation:** Monthly profile, ABB and cash-flow data are shown only as tables. Category and channel data are fetched and then discarded.
- **Trust-breaking behaviours:**
  - The 300-row cap with no indication that rows are hidden.
  - "Click to drill deeper" does not drill.
  - "Ignore Dup" is offered on balance breaks.
  - Red means both "Primary Hub" and "Critical".
  - The header mode toggle can disagree with the persisted mode.
  - The UI says "offline" while cloud AI is active.
- **Interaction design:** The Draw Tool takes typed coordinates. The layering tree uses `flex-wrap`. The graph uses straight lines, so reciprocal edges overlap. Loop arrows are probably hidden under the node circles. The suspense workbench is one row at a time.
- **Performance UX:** Every click reloads the whole case. Search has no debounce. Nothing can be sorted.
- **Accessibility:** Focus contrast is 1.25:1. No ARIA tabs. Unlabelled inputs. SVG nodes are mouse-only. Several contrast failures.

### 5.3 Redesign recommendations toward a contemporary forensic analytics product

1. **Information architecture**
   - A left sidebar (Linear/Chainalysis Reactor style) with the case switcher at the top.
   - The workflow steps for the case's mode (Edge or Trace), with the other product under "More".
   - Hash routing (`#/case/:id/trace/mules`), a ⌘K command palette, and a single contextual Export menu.
   - Runtime and agent settings moved into a status popover, plus a persistent **"Cloud AI enabled"** banner whenever egress is possible.
2. **Design system**
   - Semantic tokens (`--risk-critical/suspicious/low`, `--node-*`, `--surface-*`) used through CSS classes in SVG, a dark theme, a self-hosted Inter, an icon set, and toasts.
   - A compact INR formatter (₹1.2 L / ₹3.4 Cr) with exact values in tooltips, `−₹` negatives, right-aligned numeric columns, and Dr/Cr colour.
3. **Data grid:** Server-paginated and virtualised (e.g. TanStack Table core), with sortable headers (`aria-sort`), column filters (date, amount, channel, category, flag), saved views, an "X of Y" counter, and export of the current view.
4. **Evidence-first explainability**
   - A mule contribution waterfall (w·S·100 summing to the score) with raw metric and reason per parameter, and an evidence drawer of flagged transactions.
   - Provenance badges (`OCR_AUTOCORRECTED`, `LLM_REPAIRED`, `USER_RULE`) on every row, with a before/after diff.
5. **Network graph**
   - A canvas or WebGL renderer (sigma.js or Cytoscape) for scale, with curved reciprocal edges.
   - A "Colour by" toggle (role / statement status / mule tier) and a time-range brush slider.
   - IFSC and branch filters, neighbour highlighting on hover, and a side inspector panel instead of jumping tabs.
   - Ego-network mode, and the top-N nodes with expand-on-demand.
6. **Layering:** A tidy-tree SVG with elbow connectors, amount and date labels on edges, lazy expansion, breadcrumbs after re-rooting, a FIFO vs All-outflows toggle, and Misc groups per branch with named restore.
7. **Loops and bidirectional:** Curved arcs labelled "₹amt · date · channel" with the UTR in a tooltip and leakage shown under each node. A mirrored A→B / B→A timeline with a cumulative-net step line and a ranked pair picker.
8. **Profile:** KPI cards (opening, closing, credits, debits, net, ABB, active accounts, mule tier), a monthly trend chart, a category treemap, a channel donut, top-15 parties by resolved entity, and one-click PDF, XLSX and HTML export.
9. **Ingestion:** A drag-and-drop queue with per-file status chips and progress, a filename-convention parse preview with warnings, a password field per file plus a metadata-based password generator, and a background job with progress and cancel.
10. **Draw Tool:** Page raster with a draggable bbox and dividers, a field dropdown per column, page navigation, and a live parsed-row preview.
11. **Suspense and entities:** Suspense grouped by counterparty or pattern with count and total, bulk assignment with a propagation preview and undo. A live merge preview linked to the slider, with Confirm, Reject and Split per cluster.
12. **Accessibility (WCAG 2.2 AA):** Visible focus (2 px outline), ARIA tabs, labels, `aria-live` status regions, keyboard graph navigation with a tabular alternative, and colour pairs that pass 4.5:1 or 3:1.

## Appendix A: Refuted and corrected claims

No finding was refuted outright. The verification pass corrected or downgraded these claims:

- **EDGE-01, LLM-04, LLM-05, BE-01:** The wildcard ACAO header appears only on OPTIONS, so a cross-origin page cannot read responses. The real enabler is `text/plain` bodies being parsed as JSON, plus the missing Origin and Host checks. Real case IDs are random (`CASE_` plus 10 hex), so exfiltration needs the fixed demo IDs or DNS rebinding. EDGE-01 and LLM-05 were downgraded to medium; BE-01 stays critical as the consolidated item.
- **BE-02:** Downgraded from critical to high. The default bind is 127.0.0.1, and RBAC is "optional" and in Phase 5 of the SRS.
- **PDF-01:** The ">600 s at 22 glyphs" figure was not reproduced (about 2 s at 22, doubling per glyph). "NET/MARKET trigger it" is wrong: only a standalone `(ET)` or `BT` word triggers it.
- **PDF-02:** Downgraded to medium. Only a standalone "ET" inside a string triggers it.
- **PDF-05:** The secondary example `UPI/1234ABC.00` does not trigger. A plain `Account Name:John Doe` header does, which makes the problem broader.
- **PDF-06 / PDF-07 / PDF-12:** Impact overstated. The stream fallback and Poppler recover most text. The bomb is a local DoS. pikepdf is declared in `pyproject.toml` but not in `requirements.txt`, and password-protected text PDFs still parse through Poppler.
- **ING-04:** The "7/8 BALANCE_MISMATCH" count was not observed. The parse produced **no warnings**, which is worse. The PDF failure is in the shared mapping loop, not at line 472.
- **ING-03:** Downgraded from critical to high because only fixed-width `.txt` files are affected.
- **TG-01:** The claim that mirrored rows are double counted is refuted for Details-Only entities. Channel mix is not inverted.
- **TG-02:** Downgraded to medium because the wrong opening and closing values are not currently displayed.
- **TG-05:** "False accommodation-entry alerts" is refuted. The count is a display KPI only.
